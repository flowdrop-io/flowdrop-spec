## What it means

Presence and value are judged separately, as JSON Schema judges them. A
required key set to `null` is present, so it satisfies the requirement. Its
value is then checked like any other: `null` is a type of its own, so it fails
a key whose type does not admit it, and it fails an `enum` that does not list
it. Bounds and `pattern` describe numbers and strings, and say nothing about a
`null`.

## Example

A required key whose schema is `{ "type": "string", "minLength": 5 }`:

```json title="A required key set to null" verdict="refused"
{"url": null}
```

The requirement is met, but `type` refuses the value. With
`{ "type": ["string", "null"], "minLength": 5 }` the same config is accepted.
