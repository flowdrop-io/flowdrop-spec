## What it means

Stripping reaches every key the node's effective output schema names as a
port: the outputs its processor declares and the dynamic outputs the instance
adds (DYN-8). A reserved control port is not in that schema, so it passes
straight through.

The obligation holds even where the processor's own schema declares no output
ports at all. An empty declared set is not licence to leave a hidden port
unenforced; a hidden dynamic output on such a node is stripped all the same.

## Example

A node's result carries three keys: a declared output the node keeps visible,
a declared output the node type hides, and a dynamic output this instance
hides.

```json title="A node's raw result" verdict="produced"
{"result": "ok", "summary": "draft", "ssn": "secret"}
```

```json title="What the result delivers" verdict="stripped"
{"result": "ok"}
```
