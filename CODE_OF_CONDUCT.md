# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc], in full.

Read it here: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

**In short:** be decent. Critique documents, not people. Assume the person you
disagree with has a reason you have not heard yet; in a specification, they
usually do.

## Reporting

Report unacceptable behaviour to **shibin@factorial.io**. Reports are handled
confidentially by the maintainers, who will respond within a reasonable time and
respect the reporter's privacy.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
