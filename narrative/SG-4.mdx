## What it means

An empty array is not a loop that runs zero times — it is completion on the
first round, with the node's whole defined output set produced immediately,
current item included as absent rather than left unset. A value that is not
an array at all is not refused either: it is wrapped as the one item a single
round iterates, re-indexed the same way any array would be, so a round that
receives a bare scalar behaves exactly like a round over a one-item array.

## Example

```json title="A ForEach launched with no items"
{"items": []}
```

```json title="What it emits on that round" verdict="completed"
{"loop_active": false, "current_item": null, "total_count": 0, "collected_results": []}
```

```json title="A ForEach launched with one scalar, not an array"
{"items": "scalar_value"}
```

```json title="What it emits on that round" verdict="wrapped"
{"current_item": "scalar_value", "current_index": 0, "total_count": 1, "is_first": true, "is_last": true}
```
