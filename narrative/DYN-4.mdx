## What it means

A dynamic input with nothing wired to it is left out of a node's resolved
inputs. A processor reading its inputs tells "nothing arrived" from "a `null`
arrived" by checking for the key: the key is there only when something was
delivered, and its value is `null` only when a `null` was.

## Example

A node declares two dynamic inputs, and only one has anything wired to it:

```json title="A dynamic input with nothing wired to it"
{ "dynamicInputs": [{ "name": "connected", "label": "C", "dataType": "string" }, { "name": "unconnected", "label": "U", "dataType": "string" }], "connected": "value" }
```

```json title="What resolving the node's inputs returns" verdict="absent"
{ "connected": "value" }
```
