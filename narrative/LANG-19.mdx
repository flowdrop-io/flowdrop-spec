## What it means

Extracting all matches never hands back the bare value it found — even where
the path can only ever match one thing, the result is still an array, so
calling code does not need two shapes depending on what the path looked
like. The sharper edge is the null case: a path that reads a stored null
found something, so it comes back as a one-element array holding that null.
Only a path that matched nothing at all gives the empty array.

## Example

Extracting all matches for `store.name`, a path that can only ever match one
value:

```json title="What extracting all matches returns for a single match" verdict="wrapped"
["Test Store"]
```

```json title="A context whose path reads a stored null" verdict="matched"
{"key": null}
```

```json title="What extracting all matches returns for it" verdict="wrapped"
[null]
```
