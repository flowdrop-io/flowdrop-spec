## What it means

A caller who sends a key the workflow does not declare has made a mistake it
cannot see: a typo in an input name looks exactly like a valid request. A
launch that dropped the key quietly would run with the caller's intent
missing. So every externally reachable launch endpoint refuses the request,
and the refusal names both the key and the workflow, because the caller is
often a machine and the message has to be enough on its own.

The last sentence says what the refusal protects: an undeclared key never
reaches the resolved initial data. The internal node-keyed shape (MAN-12) is
not a launch key in this sense, and is refused for its own reason.

## Example

```json title="A key that is not a declared input name" verdict="refused"
{ "nmae": "typo" }
```

The refusal names `nmae` and the workflow it was sent to, and no run starts.
