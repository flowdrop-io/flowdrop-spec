## What it means

A string that does not match its schema's `pattern` is refused. A pattern that
is not a valid regular expression is a different case: the schema is invalid,
and that is the node type's defect, not the author's. The node type cannot be
built (SCH-24), and R6 does not judge the node's config at all (R6.j), so the
author is not blocked by a mistake they cannot fix.

## Example

```json title="The value assigned to a key requiring an https prefix" verdict="refused"
"ftp://example.com"
```
