## What it means

The unified output port's description lists every output that is exposed on
the node, as EXPO-2 resolves it. The unified port does not repeat whatever
exposure logic governs the ordinary port list — it simply reads the same
exposed/hidden verdict for each key.

## Example

A node type's output includes `visible_out`, which states `exposedByDefault: true`,
and `hidden_out`, which states `false`; the instance overrides neither.

```json title="The unified output port's description" verdict="listed"
"All outputs as JSON object. Available keys: visible_out"
```

`visible_out` enumerates because it is exposed; `hidden_out` does not.
