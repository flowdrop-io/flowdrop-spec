## What it means

The weight is the whole of the ordering this rule asks for. A field without one
weighs 0, so it sits with every other unweighted field, before any field weighted
above 0 and after any weighted below it. How fields of equal weight are laid out
among themselves is left to the implementation: an author who needs a fixed order
gives each field its own weight.

## Example

Two grouped properties, `first` weighted ahead of `second`:

```json title="Two grouped properties, first weighted 20 and second weighted 10" verdict="declared"
{
  "first": { "type": "string", "x-group": "general", "x-config-order": 20 },
  "second": { "type": "string", "x-group": "general", "x-config-order": 10 }
}
```

```json title="What the generated layout orders them into" verdict="reordered"
["#/properties/second", "#/properties/first"]
```
